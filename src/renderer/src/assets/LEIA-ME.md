# Logo de interface (UI)

Coloque aqui o logo que aparece DENTRO do app (tela de login e cabeçalho).

- Nome sugerido: `logo.png` (fundo transparente) ou `logo.svg`
- Tamanho recomendado: PNG com pelo menos 256px de altura (ou SVG, que escala sem perder)

Depois de soltar o arquivo aqui, me avise o nome que eu ligo ele na UI
(troco os ícones 🔐 da tela de login e do cabeçalho pelo logo real).

Como é referenciado no código (exemplo):

    import logo from '../assets/logo.png'
    <img src={logo} alt="Inside" />
